# Crypto Fees

Estensione Chrome (Manifest V3) che mostra le fee di rete di Bitcoin (sat/vB) ed Ethereum (Gwei),
con costo stimato nella valuta scelta di una transazione tipica e badge sull'icona con la fee BTC "veloce".

- BTC: mempool.space · ETH: `eth_feeHistory` su RPC pubbliche · Prezzi: CoinGecko
- Prezzi spot con variazione 24h. Costo stimato: BTC 141 vB, ETH trasferimento semplice 21.000 gas ; valuta selezionabile dal popup (USD, EUR, GBP, CHF, JPY). Oro: prezzo di PAXG (token ancorato a 1 oz)

## Installazione
`chrome://extensions` → Modalità sviluppatore → "Carica estensione non pacchettizzata" → cartella del repo.
